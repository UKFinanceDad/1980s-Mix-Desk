# Neon Nights Mix Board

A browser-based, two-deck mix board for live 80s-style DJ sets. Open `index.html` in Chrome, Edge, Firefox or Safari and press **Power on**. No install, no build step.

## What's on the board

- **Two decks**, each with five original tracks synthesized live with the Web Audio API: Night Drive (synthwave), Disco Lights (Italo disco), Pop & Lock (electro funk), Neon Wave (new wave) and Heartlight (power ballad).
- **Stems** on every deck: drop Drums, Bass, Keys and Lead in and out.
- **Mixer**: 3-band kill EQ, a one-knob low/high-pass filter and a channel fader per deck, VU meters, and an equal-power crossfader.
- **Master effects**: tempo-synced echo, reverb, a master low-pass sweep, plus hold-to-use Echo throw and Gate chop.
- **Eight hit pads**: orchestra hit, brass stab, gated snare, hex tom, cowbell, handclap, laser zap and a two-bar riser.
- **Your own audio**: load or drop any audio file onto a deck. It loops from the next bar, and the Key knob changes its tape speed.
- Decks start on the next bar so they stay in time. Tempo runs 80 to 150 BPM, with tap tempo.

## Keys

`Q` / `P` play deck A / B · `1`–`8` pads · `Z` / `X` crossfader · hold `E` echo throw · hold `G` gate chop.

All music is original and generated in the browser. No samples or copyrighted recordings are included.
